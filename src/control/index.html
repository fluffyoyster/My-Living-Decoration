Engine settings

Audio sourceiSystem audio reacts to whatever Windows is playing (Spotify, YouTube, games). Microphone reacts to the room instead.
QualityiAuto watches the frame time and moves between four tiers (resolution, spore count, flame samples). Pick a fixed tier if you prefer a constant look.
FPS capiUpper limit on frames per second. Lower caps save GPU and battery; 60 is plenty for a wallpaper.
Pause when an app is fullscreeniStops rendering while a game or video covers a monitor, so the wallpaper never steals frames from it.
Start with WindowsiLaunches the engine (in the tray) when you log in.
Pause everythingiFreeze all wallpapers until unpaused. The tray menu has the same switch.
Closing this window keeps the wallpapers running from the tray icon.
